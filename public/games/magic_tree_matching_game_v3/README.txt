MAGIC TREE MATCHING GAME - V3 LONG-ROPE FRAME

How to run
1. Extract the ZIP file.
2. Open index.html in Chrome on desktop.
3. Click the animal that matches the word in the basket.

What changed in V3
- Replaced the old two-short-rope card frame with the approved new frame:
  two side ropes join into one long center rope, with a knot at the top end.
- Repositioned animal art inside the new taller frame.
- Rebalanced the four card positions for the longer hanging rope.
- Clean background remains separate from all gameplay/UI assets.

Included
- Clean desktop backgrounds: 1920x1080 and 2560x1440
- New long-rope hanging card frame + @2x + high-resolution source
- Separate transparent PNG animals: dog, cat, monkey, chicken
- Basket + answer plaque
- Stars panel + filled/empty stars
- Score panel
- Sound on/off icons
- Squirrel mascot + speech bubble
- Instruction sign, signpost, encouragement rock
- index.html, style.css, game.js

Gameplay
- 4 clickable animal choices
- Correct/wrong feedback
- Score system

- English speech synthesis
- Sound toggle
- Confetti and animations
- Finish screen and Play Again button

Important
The answer word, score, instruction text, and speech bubble text are HTML/CSS text, not baked into the background.
