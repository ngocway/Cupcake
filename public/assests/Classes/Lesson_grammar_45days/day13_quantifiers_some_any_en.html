🗺️ GRAMMAR MAP: Quantifiers: Some & Any in Statements and Questions
1. Some: positive statements
books → some books
I have some books in my bag.
💡 Books is a plural countable noun; some means an unspecified number.
apples → some apples
Mom buys some apples for lunch.
💡 Apples is plural and we are making a positive statement, so some is natural.
2. Any: negatives and neutral questions
some notebooks → any notebooks?
Do you have any notebooks?
💡 The speaker checks availability without expecting a particular answer.
some milk → any milk?
Is there any milk in the kitchen?
💡 Any fits a neutral question about an uncountable amount.
3. Some in offers / requests; any in positive “no matter which”
an unknown person → some student
Some student left a notebook here.
💡 Some means a student whose identity the speaker does not know or name.
whichever pencil → any pencil
Any pencil will work for this activity.
💡 Any means whichever single pencil you choose is acceptable.

📖 1. Detailed Rules & Spelling Patterns

1. Some + plural countable nouns

Use some to mean an unspecified number in ordinary positive statements.

books → some books
I have some books in my bag.
💡 Books is a plural countable noun; some means an unspecified number.
apples → some apples
Mom buys some apples for lunch.
💡 Apples is plural and we are making a positive statement, so some is natural.

2. Some + uncountable nouns

Use some for an unspecified amount of uncountable substances or ideas.

water → some water
Please give me some water.
💡 Water is uncountable; some describes an amount, not separate waters.
rice → some rice
We have some rice for dinner.
💡 Rice is uncountable in this use, and some expresses an unspecified amount.

3. Any in negative statements

Use not ... any with plural countable or uncountable nouns to mean none.

some pencils → not any pencils
I don’t have any pencils today.
💡 The negative don’t combines with any to mean zero pencils.
some juice → not any juice
There isn’t any juice in the fridge.
💡 The negative isn’t with any means no juice remains.

4. Any in neutral Yes/No questions

Use any when checking whether something exists or is available without assuming yes.

some notebooks → any notebooks?
Do you have any notebooks?
💡 The speaker checks availability without expecting a particular answer.
some milk → any milk?
Is there any milk in the kitchen?
💡 Any fits a neutral question about an uncountable amount.

5. Some in offers and requests

Use some in questions when offering something or requesting something, often when a yes answer is expected.

offer tea → some tea?
Would you like some tea?
💡 This is an offer rather than a neutral inventory question, so some is natural.
request help → some help?
Could I have some help with this homework?
💡 The speaker is requesting help; some is idiomatic in polite requests.

6. Any in positive sentences meaning “whichever”

In affirmative statements, any can mean it does not matter which member of a set.

choose whichever book → any book
You can choose any book from this shelf.
💡 Any means there is no restriction on which book you choose.
whichever day → any day
We can meet on any day next week.
💡 Any means each day is an acceptable option, not an unspecified quantity.

7. Some / any with singular count nouns: special meaning

Some + singular count noun can mean an unspecified person or thing; any + singular can mean whichever one. These are not basic quantity uses.

an unknown person → some student
Some student left a notebook here.
💡 Some means a student whose identity the speaker does not know or name.
whichever pencil → any pencil
Any pencil will work for this activity.
💡 Any means whichever single pencil you choose is acceptable.

🎯 2. Real-World Usage Scenarios

School supplies

I have some pens, but I don’t have any markers.
Do you have any paper?

At the lunch table

Would you like some juice?
No, thanks. I don’t want any juice.

Choosing a book

You may borrow any book from this box.
Could I have some help choosing one?

⚠️ 3. Common Mistakes: Wrong vs Right

MISTAKE 1
❌ I don’t have some pencils.
✅ I don’t have any pencils.
💡 In an ordinary negative statement meaning zero pencils, use any.
MISTAKE 2
❌ Do you have some milk? (neutral check)
✅ Do you have any milk?
💡 For a neutral availability question, any is the usual choice. Some may suggest an expectation.
MISTAKE 3
❌ Would you like any cake? (offering a portion)
✅ Would you like some cake?
💡 An ordinary offer of a portion is more naturally phrased with some.
MISTAKE 4
❌ There aren’t any water.
✅ There isn’t any water.
💡 Water is uncountable, so use singular agreement isn’t.

❓ Quick FAQ

Is some always wrong in questions?

No. It is common in offers and polite requests: “Would you like some fruit?”

Can any appear in a positive statement?

Yes, when it means “whichever”: “Choose any seat.”

Can I use some with water?

Yes. Some can describe an unspecified amount of an uncountable noun.
