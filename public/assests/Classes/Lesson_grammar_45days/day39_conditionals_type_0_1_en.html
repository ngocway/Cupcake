🗺️ GRAMMAR MAP: Conditionals: Zero & First Conditional
Zero conditional: if + present, present
if + heat → melts
If you heat ice, it melts.
💡 Heating ice regularly produces melting, so both clauses use present simple.
if + rain → gets wet
If it rains, the ground gets wet.
💡 This describes a repeatable result rather than one future event.
Unless = if not
if you do not hurry → unless you hurry
You will be late unless you hurry.
💡 Unless you hurry means if you do not hurry.
if it does not stop → unless it stops
We won’t go out unless it stops raining.
💡 Unless it stops expresses the condition for going outside.
When vs if for certainty
when + arrive → will call
When I arrive, I will call you.
💡 Arrival is expected; the time clause uses present simple.
if + arrive → will call
If I arrive early, I will call you.
💡 Arriving early is uncertain, so use if.

📖 1. Detailed Rules & Spelling Patterns

Zero conditional: if + present, present

Express general truths or regular results.

if + heat → melts
If you heat ice, it melts.
💡 Heating ice regularly produces melting, so both clauses use present simple.
if + rain → gets wet
If it rains, the ground gets wet.
💡 This describes a repeatable result rather than one future event.

First conditional: if + present, will + V1

Express a realistic possible future condition and its result.

if + study → will pass
If you study, you will pass the test.
💡 The condition is possible; will predicts its future result.
if + rain → will stay
If it rains, we will stay home.
💡 Use present rains after if, not will rain.

Unless = if not

Unless introduces a negative condition without adding another not.

if you do not hurry → unless you hurry
You will be late unless you hurry.
💡 Unless you hurry means if you do not hurry.
if it does not stop → unless it stops
We won’t go out unless it stops raining.
💡 Unless it stops expresses the condition for going outside.

Comma with opening if-clause

Put a comma after the initial conditional clause.

If it rains, → comma
If it rains, the match will stop.
💡 The initial if-clause is separated by a comma.
main clause + if → no comma
The match will stop if it rains.
💡 An if-clause at the end normally needs no comma.

When vs if for certainty

When implies an expected event; if leaves it uncertain.

when + arrive → will call
When I arrive, I will call you.
💡 Arrival is expected; the time clause uses present simple.
if + arrive → will call
If I arrive early, I will call you.
💡 Arriving early is uncertain, so use if.

⚠️ 3. Common Mistakes: Wrong vs Right

MISTAKE 1
❌ If you heat ice, it will always melts.
✅ If you heat ice, it melts.
💡 Heating ice regularly produces melting, so both clauses use present simple.
MISTAKE 2
❌ If it will rain, we will stay home.
✅ If it rains, we will stay home.
💡 The condition is possible; will predicts its future result.
MISTAKE 3
❌ Unless you don’t hurry, you will be late.
✅ Unless you hurry, you will be late.
💡 Unless you hurry means if you do not hurry.
MISTAKE 4
❌ If it rains we will stay home.
✅ If it rains, we will stay home.
💡 The initial if-clause is separated by a comma.
